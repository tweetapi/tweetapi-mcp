# Security

If you find a security issue in this server or in the hosted service at `mcp.tweetapi.com`, please
email <support@tweetapi.com> instead of opening a public issue. Include steps to reproduce and what
an attacker could do with it. We'll reply as soon as we can and keep you updated while we fix it.

Please don't run load tests or automated scans against the hosted service, and don't access data
that isn't yours.
